### Passo a Passo:

1. **Clone este repositório no seu terminal:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. **Suba toda a estrutura de microsserviços:**
   ```bash
   docker compose up -d
   ```
